# Quotezia - Your Daily Inspiration App

تطبيق للاقتباسات الملهمة يومياً مع دعم اللغتين العربية والإنجليزية.

## الميزات

- 🌟 اقتباسات ملهمة يومية
- 🌍 دعم اللغة العربية والإنجليزية
- 🎨 واجهة مستخدم جميلة وسهلة
- 🔔 إشعارات يومية
- 📤 مشاركة الاقتباسات
- 💎 اشتراك Premium لإزالة الإعلانات
- 🌙 الوضع الليلي

## المتطلبات التقنية

- Flutter SDK: ^3.10.3
- Dart SDK: ^3.10.3

## التبعيات الرئيسية

- `google_mobile_ads` - إعلانات AdMob
- `in_app_purchase` - الشراء داخل التطبيق
- `flutter_local_notifications` - الإشعارات المحلية
- `share_plus` - مشاركة المحتوى
- `hive` & `hive_flutter` - التخزين المحلي
- `provider` - إدارة الحالة

## البناء والتشغيل

```bash
# تثبيت التبعيات
flutter pub get

# تشغيل التطبيق
flutter run

# بناء iOS
flutter build ios --release

# بناء Android
flutter build appbundle --release
```
